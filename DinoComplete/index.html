DinoComplete: 3D Shape Completion with Distilled Semantic Priors and State Space Models

Abstract

3D shape completion from partial scans remains challenging for unseen categories and noisy real-world observations, where geometry alone is often insufficient for inferring missing structure. We present DinoComplete, a deterministic and efficient shape completion framework that augments geometric reconstruction with voxel-aligned semantic priors distilled from DINO features. First, we construct multi-view DINO feature volumes aligned with ShapeNet data and train a student network to predict dense semantic features directly from incomplete shapes. These predicted features capture global structure and part-aware semantic context while remaining aligned with the underlying geometry. We then integrate these distilled features into a completion network, where geometric and semantic voxel representations are fused through voxel state-space modeling. To enable efficient long-range reasoning without sacrificing resolution, we introduce a Multi-Scale Voxel Mamba module that refines the fused features by combining full-grid and chunk-wise sequence modeling. Experiments on unseen ShapeNet categories and ScanNet objects show that DinoComplete achieves competitive completion quality relative to prior deterministic and generative completion methods while using fewer parameters, requiring lower memory, and achieving faster inference. Our results demonstrate that distilling semantic priors from visual foundation models improves generalization and robustness in 3D shape completion.

Method Overview

A geometric branch and a distilled semantic branch encode the same partial scan. Voxel state space operators fuse their features, and Multi-Scale Voxel Mamba refines the decoded volume into a complete shape.

Distill Semantics into 3D

We fuse DINOv3 features from 20 rendered RGB-D views into a voxel-aligned teacher volume. A 3D student learns to predict the observed semantic features directly from a partial TSDF, transferring visual priors into a geometry-only model.

Reason Across Multiple Scales

Multi-Scale Voxel Mamba combines a full voxel sequence with shorter chunk-wise sequences. Hilbert-curve serialization preserves spatial locality, while residual aggregation combines local detail with long-range context.

Semantic Structure from Incomplete Scans

The TSDF-DINO student predicts features on unseen categories that resemble the teacher features. PCA visualizations reveal similar feature patterns on semantically related parts, even across different object categories.

Quality and Efficiency

DinoComplete achieves the best average Chamfer Distance and IoU among the compared methods on unseen ShapeNet categories, with competitive performance on real ScanNet objects.
